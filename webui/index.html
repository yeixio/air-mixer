Universal Audio Protocol Translator & Mixer

How it works: Add Input Servers to receive audio → Create Routes to connect sources to destinations → Add Output Clients to send audio to your speakers. Audio flows from inputs through routes to outputs.

Input Servers

What are Input Servers?
Input Servers receive audio from external sources on your network. When you add an AirPlay server, it appears as an AirPlay speaker that other devices can connect to. Audio sent to these servers becomes available for routing to your output devices. For example, create an AirPlay server to receive audio from your iPhone, iPad, or Mac.

Output Clients

What are Output Clients?
Output Clients are destinations where audio is sent. These represent physical or network speakers that you want to play audio on. Add an output client for each speaker or audio device you want to control. When you create a route, you'll connect input servers to these output clients to define where audio should play.

Audio Routes

What are Routes?
Routes connect your Input Servers to Output Clients, defining how audio flows through the system. A route specifies which input source (like an AirPlay connection) should send audio to which output destinations (like speakers). You can route one source to multiple outputs, or mix multiple sources together. Routes must be enabled to be active.
